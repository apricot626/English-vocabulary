# TOEIC単語帳

TOEIC頻出単語を **フラッシュカード** と **4択クイズ** で覚えるための、ブラウザだけで動く単語帳アプリです。
HTML / CSS / バニラJavaScript のみで作られていて、ビルドもサーバーも必要ありません。

## 特徴

- **320語を収録** — レベル別・種類別の4つの単語帳（各80語）
- **フラッシュカード** — タップで意味を表示。「覚えた／まだ」で仕分け
- **4択クイズ** — 10問1セット。間違えた単語は結果画面で復習できる
- **英→日 / 日→英** の両方向で出題できる
- **復習管理** — ライトナー式（間隔反復）で、覚えていない単語ほど早く再出題
- **苦手リスト** — 間違いが多い単語だけを集めて集中学習
- **音声読み上げ** — 単語と例文を英語で発音（Web Speech API）
- **英→日 / 日→英 の単語帳** — 一覧で読める辞書のような画面。「答えを隠す」で自己テストもできる
- **熟語帳** — 句動詞・熟語 80項目だけをまとめた画面
- **索引** — 全320項目をアルファベット順に引ける。日本語でも検索できる
- **丸暗記（長文）** — 全320項目を8本の英文（1本およそ500語）で網羅。和訳の表示切替つき
- **単語のイメージ図** — 全320項目に自作SVGの絵を用意。外部通信なしで完全にオフラインで動く
- **オフラインで動く** — 学習状況はブラウザの localStorage に保存。サーバーへは何も送信しない
- **データの書き出し／読み込み** — JSONで学習状況をバックアップ・端末間で移動できる
- スマホ優先のレイアウト、ダークモード対応

## 使い方

ローカルで開く場合は、`index.html` をブラウザで開くだけです。

```sh
# 簡易サーバーで開く場合
python3 -m http.server 8000
# → http://localhost:8000
```

### キーボード操作（フラッシュカード）

| キー | 動作 |
| --- | --- |
| `Space` | カードをめくる |
| `1` | まだ覚えていない |
| `2` | 覚えた |

## 単語を追加・編集する

単語データは `js/data/` の中にあります。1ファイルが1つの単語帳です。

```js
window.VOCAB_DECKS.push({
  id: 'toeic600',              // 単語帳のID（重複しない文字列）
  title: 'TOEIC 600点レベル',   // 表示名
  subtitle: '基礎ビジネス頻出語',
  color: '#2f8f6b',            // カードの色
  words: [
    {
      w: 'attend',             // 単語
      p: 'əténd',              // 発音記号（省略可）
      pos: '動',               // 品詞
      m: '出席する、参加する',   // 意味
      e: 'All managers must attend the meeting on Friday.',  // 例文
      j: '管理職は全員、金曜の会議に出席しなければならない。'   // 例文の訳
    }
  ]
});
```

単語帳を増やすときは `js/data/` に新しいファイルを追加し、`index.html` の
`<script>` タグに1行足してください。

> 学習の進み具合は「単語帳のID + 単語」で記録しています。既存の単語のつづりを変えると、
> その単語の学習記録はリセットされます。

## 丸暗記用の長文について

`js/data/passages.js` に8本入っています。1本が単語帳のちょうど1ブロック（40項目）に対応し、
8本で全320項目を漏れなく網羅します。

| 英文 | 対応する範囲 | 語数 |
| --- | --- | --- |
| Opening the New Branch | TOEIC 600点レベル ① | 527 |
| The Warehouse Year | TOEIC 600点レベル ② | 525 |
| Expanding the Hotel | TOEIC 730点レベル ① | 522 |
| Moving and Starting Over | TOEIC 730点レベル ② | 522 |
| The Acquisition | TOEIC 860点レベル ① | 509 |
| Rebuilding the Old Factory | TOEIC 860点レベル ② | 500 |
| The Spring Trade Fair | 句動詞・熟語 ① | 474 |
| Organising the Seminar | 句動詞・熟語 ② | 485 |

本文中の見出し語は自動で見つけて印をつけます。`broke down` のような不規則変化や、
`bring it up` のように語が割り込む形にも対応しています。

## 単語のイメージ図について

イメージ図は**すべてリポジトリ内で完結**しています。外部の画像サービスは使いません。
そのためオフラインでも表示され、リンク切れも起きません。

- `js/data/art.js` — 50種類の絵柄（自作SVG）と、320項目それぞれの割り当て
- `js/data/images.js` — 項目ごとの絵文字（絵柄の右下に重ねる目印）
- `js/images.js` — 上の2つを組み合わせて描く

```js
// js/data/art.js
window.VOCAB_ART.scenes = {
  warehouse: '<path class="a2" .../>' +   // a1 主役 / a2 補助 / a3 差し色 / ln 線
             '<rect class="a1" .../>'     // 色は CSS 変数なのでダークモードで自動反転
};

window.VOCAB_ART.map = {
  'warehouse': 'warehouse',   // 倉庫の絵
  'inventory': 'warehouse',   // 在庫も同じ絵
  'prudent':   'shield'       // 抽象語は意味の近い絵に寄せる
};
```

絵柄は 120×80 のキャンバスに、次の4クラスだけで描きます。

| クラス | 役割 |
| --- | --- |
| `a1` | 主役の面 |
| `a2` | 補助の面 |
| `a3` | 差し色 |
| `ln` | 線・細部（`stroke-width` を指定した要素は線として描かれる） |

色は絵柄の名前から5種類のうち1つが自動で決まるので、一覧に並べたときに見分けがつきます。

### 絵柄を足す・変えるには

1. `window.VOCAB_ART.scenes` に新しい絵柄を追加する
2. `window.VOCAB_ART.map` で、その絵柄を使いたい項目に割り当てる

絵柄は50種類を320項目で共有しています（1つの絵柄あたり平均6項目）。
意味の近い語をまとめているので、たとえば `inventory` `surplus` `replenish` は同じ倉庫の絵になります。

## ファイル構成


```
index.html          画面の骨組み（全画面を1ファイルに含む）
css/style.css       スタイル（ダークモード対応）
js/app.js           アプリ本体（画面遷移・出題・復習管理・単語帳・索引・長文）
js/images.js        イメージ図の描画
js/data/deck-*.js   単語データ（1ファイル＝1つの単語帳）
js/data/art.js      絵柄（自作SVG）と項目ごとの割り当て
js/data/images.js   項目ごとの絵文字
js/data/passages.js 丸暗記用の長文
```

## 公開する

静的サイトなので、そのまま公開できます。

- **GitHub Pages** — Settings → Pages → Source を `main` ブランチのルートに設定
- **Cloudflare Pages** — ビルドコマンドなし、出力ディレクトリはルート（`/`）
